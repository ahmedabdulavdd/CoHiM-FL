# Study-level partition manifest (derived from historical experiment logs)

`split_manifest_3337.csv` contains the **actual recorded** split membership from the five supplied September run artifacts, with:

- `partition` — Train (2,335), Validation (334), or Test (668)
- `study_uid` — dataset-provided study/report identifier
- `image_1_filename`, `image_2_filename` — file **basenames** only (absolute Colab prefixes removed)

All five recorded seed-level manifests were compared before export and were identical. This is a path-portable representation of the archived manifests, not a newly sampled partition. No images, radiology reports, patient identifiers, or label matrices are included here.

**Important:** Study-/image-level disjointness does not establish patient-level disjointness: patient IDs were not available in the supplied source metadata. The current notebooks generate train/validation/test splits deterministically; a reproduction should compare the generated study UIDs with this manifest before claiming exactly matching partitions.

### Missing-view masks
No complete per-study missing-view mask file is in the 17 source archives. However, `derived_missing_view_masks.csv` contains 6,680 rows (668 test studies × 10 evaluation conditions), deterministically regenerated by `scripts/reconstruct_missing_masks.py` from the exact integer hashing/ranking equations in the supplied main notebook and recorded test study order. The generated per-condition masked counts were checked against all five seeds' numeric archives. These are **code-derived reconstructions, not byte-identical original saved mask artifacts**; mask member-level matching to an original file is impossible without that source. The notebooks implement seeded missing-view evaluation logic. The saved numerical missing-modality summaries and status flags are available under `results/CoHiM-FL_Split_Seeds/seed_*/missing_modality_results/`. Do **not** represent a synthetic mask file as the original saved mask; export and verify real masks in a new controlled rerun if required.

The archive also includes `original_data_split_membership_seed_42.csv` and the original audit JSON. The membership CSV reproduces source absolute Google Colab paths; it is only a historical audit record, **not a portable input file**. Use `split_manifest_3337.csv` for portable UID / split checking.
